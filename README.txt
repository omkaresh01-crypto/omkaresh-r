OMKAR MOTION CRAFTERS — WEBSITE FILES

This is a complete static portfolio website with Home, About, Skills, Services, Work and Contact sections. It includes the six uploaded video files and three graphic designs.

PUBLISH TO YOUR EXISTING GITHUB PAGES REPOSITORY
1. Download and extract this ZIP on your computer.
2. Open your GitHub repository: https://github.com/omkaresh01-crypto/omkar-portfolio
3. Back up the current repository by downloading a ZIP first if you want to preserve the old version.
4. In the repository's Code tab, upload the new index.html and the assets folder contents. GitHub's browser uploader can be awkward for many large videos; if it fails, use GitHub Desktop or upload assets in smaller batches. Keep the folder paths exactly as provided.
5. The website is a single-page site, so Home/About/Skills/Services/Work/Contact are sections in index.html. The video and image assets are linked using relative paths.
6. Wait for Pages deployment, then visit https://omkaresh01-crypto.github.io/omkar-portfolio/ and hard refresh with Ctrl+Shift+R.

IMPORTANT
- The video files are included as provided. MOV playback depends on the codec inside each MOV file and browser support. If a MOV does not play on the published site, convert it to H.264 MP4 and update the source path in index.html.
- All video files are large. GitHub blocks individual files above 100 MB; the supplied individual files are below that limit, but a browser upload of all assets at once may time out.
- Contact currently links to the Motion Crafters Instagram profile. Edit the link in index.html if you want to use email or another contact method.
